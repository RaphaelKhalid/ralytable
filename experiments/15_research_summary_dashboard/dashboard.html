The synthesized result
The strongest durable idea is a small typed-rule primitive: explicit executable facts feed a tiny gate, while a compiler and verifier enforce legality.

The state-only controller reached perfect generated held-out repair rates, with state erasure changing roughly half of raw decisions. The two-parameter gates are supplied-bit routing controls, not semantic inference; their nuisance placebos are tautological. Public verification and deterministic nulls often matched final scores.

What the loop taught us

Search is a real capability multiplier

Typed sketch search lifted 52.1% raw to 89.6% hidden pass, but the deterministic null reached the same verified score. The gain belongs to the system boundary, not clearly to the learned controller.

State can be load-bearing in a synthetic control

The abstract-value and executable-Python state-only controllers changed 46–50% of raw decisions under state erasure while preserving an irrelevant placebo. This is a mechanism result, not general coding.

Compositionality is the hard crack

The explicit cross-product controller solved seen combinations perfectly, then fell to 0% on a held-out factor pair. It learned a table, not a shared rule.

Language binding remains weak

Natural-language conditional repair reached about 50% raw pass even with hybrid or cross inputs; the parser/controller split restored a fixed rule path, not open-ended semantic inference.

The experimental arc

Each stage changed the problem boundary, rather than simply shrinking a transformer.

1 · Typed sketches

Compiler legality and beam search exposed the search/null gap.

2 · State bottleneck

Abstract and executable facts became a causal control interface.

3 · Factor stress

Cross-product success broke on unseen combinations.

4 · Rule gate

Two learned scalars routed supplied typed bits through fixed rule logic.

5 · Repository boundary

Import-shaped repair passed, but remained generated and single-hole.

Bottom line

The loop found a promising architectural primitive and a clear falsification boundary.

A typed executable-state interface can be causally load-bearing in a generated repair control. The next claim—competitive, honest Python coding—was not established. The missing evidence is independent repository-local tasks with richer semantics, fewer exposed labels, and a verifier whose success cannot hide a non-causal learned policy.
