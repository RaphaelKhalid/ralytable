Raly. playground

wasm

Raly is a language being designed around vector-symbolic computation, where bind, bundle and permute are reserved as primitives rather than library calls. Its front end is built error-message-first: the diagnostic renderer was written before anything that could produce a diagnostic.

What works today. Everything on this page is the real compiler, compiled to WebAssembly and running in your browser. It runs the whole front end on every keystroke: the logos-based lexer, the recursive-descent parser, name resolution and the type system, then renders the diagnostics with the compiler's own renderer. This is the same raly::compile the command line calls, so the caret blocks below are character-for-character what raly check prints. There is no code generation yet: nothing here runs a Raly program.
