Works now

Raly reads, checks, and explains .raly files. Its new CPU interpreter runs pure constants, arithmetic, comparisons, strings, lists, and tuples, with replay receipts.

Being built

The next runtime layers are executable vector-symbolic operations, stable declaration identities, functions, and a bridge between the ledger and a learned model.

Not claimed

Ralytable is not yet a reasoning model, a replacement for Python, or proof that typed internal steps make AI trustworthy. The first learned-parser gate failed.
