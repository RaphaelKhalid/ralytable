# Experiment 28 — external leverage feasibility model

An assumption-explicit sensitivity analysis for the claim that a 40M typed
coder could rival a much larger coder on a declared distribution. It separates
exact module coverage, retrieval hit rate, parser accuracy, verifier beam
search, and residual novel-task synthesis.

This is not a benchmark or a measurement of Qwen. It answers: what conditions
would have to hold before a comparison is worth running?

Run `python leverage_model.py`.
